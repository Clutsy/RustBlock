How it works

Nothing is overwritten until it is verified.

The pipeline is deliberately boring: read the source without touching it, write a temporary GGUF beside the destination, compare, then rename. If anything fails, the original stays exactly where it was.

  1. 01

    Drop a model

    Drag one or many .gguf files. RustBlock reads the header, flags already-quantized sources and shows the fit verdict.

  2. 02

    Pick a target

    All twenty-two formats are visible at once, with hover notes and a recipe engine that follows llama.cpp's mixed K-quant rules.

  3. 03

    Verify and move on

    Structure by default, Full when it matters. Finished models can be copied straight into a detected runtime.

PowerShell — rustblock 
$ rustblock convert model-F16.gguf model-Q4_K_M.gguf `
    --to q4_k_m --verify structure
→ reading header              ok
→ 291 tensors · 16 threads    ok
→ Q4_K_M mixed recipe         ok
→ structure verification      passed
→ output written              done

The CLI and the desktop app share the same native core. The GUI adds the queue, fit badges and runtime hand-off.

Straight answers

Before you ask.

Does it need Python, Node.js or llama.cpp?

No. Conversion, quantization, reblocking and verification are native Rust. Optional integrations can call llama-bench, llama-imatrix or Ollama when those tools are installed, but they are never required to convert a model.

Is my model uploaded anywhere?

Never. Conversion runs locally and offline. Network access is used only for an explicit Hub search, a download you requested, or the update check.

What happens if verification fails?

The temporary output is discarded. The source file was opened read-only and is never modified.

How do updates work?

The installed build asks GitHub for the latest release on launch. Settings → Updates shows the new version, downloads the per-user installer and restarts when it is ready. No elevation prompt is involved.

Can I script it instead?

Yes. The rustblock CLI shares the same native core: inspect, verify, convert, fit, split, merge, download and more. Every conversion exposes the same verification levels as the app.

Which platforms are supported?

The published builds target Windows 10 and 11 on x64, as both a per-user installer and a portable ZIP.
